# Tasty Burgers

A responsive **React + TypeScript + Vite** burger shop web app.

## Features

- Tasty Burgers poster-inspired red and yellow visual design
- Philippine peso (₱) pricing
- Burger and fries menu
- Provided fries product images
- Ratings and review counts
- Local favorites with clickable heart controls
- Search and category filters
- Cart with plus/minus quantity controls
- Animated solo hero burger
- Responsive navigation and cart drawer
- Reduced-motion accessibility support

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
